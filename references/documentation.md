# 图文归档与教程

按“输入长什么样 → 怎么操作 → 输出长什么样 → 应该检查哪里 → 文件在哪”写每一步。目录说明融进对应步骤，文末再提供查找表。必要图片：原片镜头类型、身份卡、首中尾、真正送入模型的素材、ComfyUI接线、首/二阶段、映射索引、接段连续帧、修复前后和最终包装。

截图或取帧必须来自实际工程，标源帧/文件时间、版本与来源；多图拼贴每格写清楚。检查哪一版失败、哪一版进成片，不能混用。若图已由外部工具返回素材ID，保存ID与采用文件SHA。

ComfyUI历史截图缺失时，从真实API图重绘关系并标注“依据真实API JSON重绘，非历史界面截图”。不能生成虚构界面当运行证据。当前复现画布可新截图，但要标新复现日期和版本。系统界面截图使用已提供的计算机工具，只截图相关窗口并检查隐私。

本包README和画廊已附24组图，图源记录在assets/image-manifest.json。模型权重、完整MV及完整生成视频不在包内；不要因教学用途自动认定外部素材可自由发布。

若用户要求飞书：优先使用可用的目的地连接器，否则在已登录的飞书客户端正常编辑/导入。当前示例文章可从F4案例链接访问，但文章链接不保证对所有读者开放，不因教程制作扩大分享权限。常用做法是先构建DOCX、渲染逐页查看中文/裁切/图注，再导入在线文档；在原文章追加时核实正文、目录、图片和“已保存到云端”，不能只看本地DOCX或上传成功。

没有历史截图就如实说明。若外部登录或权限不通，先交付本地图文包，清楚记录待上传；不要声称文章里已有图片。保留原文、补充和图片清单的本地版本；在线追加成功不代表旧本地基础DOCX已自动合并。
